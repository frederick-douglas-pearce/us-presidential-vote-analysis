## The serving layer

`usvote/api/` is the **serving layer** (E8-S2, #96 / D028/D031) — a FastAPI subpackage (D015), *not* an EC-domain top-level module: it sits **downstream** of the snapshot artifact and imports **only** the snapshot file + a thin `SnapshotRepository` + the stdlib-only `snapshot_schema`/`config`. It must never import `usvote.db`, psycopg2, `usvote.snapshot` (the build module, which drags pandas + the DB stack), or pandas — the D028 "no live DB at serve time" property made **structural**, enforced by `tests/unit/test_api_import_graph.py` (mirroring the greppable `dwh.votes` / `usvote.warehouse` guards). Layout: `app.py` (the `create_app()` factory + `/health` + the `/v1` router), `config.py` (`ApiSettings` — snapshot path via `config.snapshot_path_from_env(must_exist=True)`, CORS allow-list, `/v1` prefix), `repository.py` (the read-only+immutable SQLite seam; reads `schema_version` **first** — before the full `snapshot_meta` row, so an older-schema snapshot reports a version mismatch rather than a missing column (D069(f)) — then caches the meta row, fails loud at startup, and — E8-S3 — the capped by-year/state/candidate read methods), `cache.py` (the content-hash ETag + `Cache-Control` + conditional-304 machinery, pure-tested), `models.py` + `routes.py` (E8-S3), and `__main__.py` (`python -m usvote.api serve`). Serve it with `python -m usvote.api` or `uvicorn --factory usvote.api:create_app`.

The **E8-S3 read endpoints** (#97; widened to 1824 in #139) live in `routes.py` on their own `/v1` router and read *only* through `SnapshotRepository` (no SQL/parsing/aggregation/computation in handlers — the roll-up and slug are precomputed in the snapshot): `GET /v1/elections` (list covered years), `/v1/elections/{year}` (per-state rows + a sibling national `summary`), `/v1/elections/{year}/summary` (the precomputed `national_rollup`), `/v1/states/{usps}`, `/v1/candidates/{slug}` (the public slug, never `candidate_id` — D006), and — since #245 — `/v1/elections/{year}/per-capita` and `/v1/states/{usps}/per-capita`. Every response is a typed Pydantic model in the shared `{data, meta}` envelope where `meta.count == len(data)`; snapshot columns are renamed to public field names via `validation_alias` (`president_electoral_votes` → `electoral_votes`, `candidate_votes` → `popular_votes`, …), guarded against drift by a model↔column completeness test. Filters: `state`/`candidate` on the year endpoint, `year_from`/`year_to` on the multi-year ones (bad/inverted params → 422). A missing path identifier → typed **404**; an empty *filter* on a known resource → **200** empty. Since #139 a **pre-1976 year is no longer a 404** — it returns 200 with its EC facts, null popular votes and a `pv_status` per row; only a year that was never an election in scope (1800, 1837) 404s, and the message names the served window and the popular-vote sub-window separately. `/v1/elections` carries `has_popular_vote` per year so "which years can I compare PV for" needs no second call. The data routes call `cache_dependency` **manually after** the existence check (not as a blanket router dependency) so an unknown resource returns 404, never a 304. A server-side `MAX_ROWS` cap fails loud rather than silently truncating. OpenAPI/Swagger polish is **E8-S4**.

## The container

The API also ships as a **cloud-agnostic container** (E8-S6, #100 / D032). Build the snapshot first, copy it into the build context, then `docker build` + `docker run` (the running image needs no DB — the snapshot is baked in, so snapshot-version == image-version):

```
python -m usvote.snapshot                    # build the snapshot (needs the warehouse incl. census)
cp "$USVOTE_API_SNAPSHOT_PATH" ./api_snapshot.sqlite   # into the build context (git-ignored)
docker build -t usvote-api .                 # slim (~150MB): serve-only deps, snapshot baked in
docker run --rm -p 8080:8080 usvote-api      # listens on $PORT (default 8080); curl /health
```

The image is **slim by design** ([D033](.claude/specs/decisions.md)): `usvote/api/` imports only FastAPI + stdlib (the D028 import-graph invariant), so the container installs the package `--no-deps` plus the lock-pinned `serve` dependency-group — the heavy stack (pandas/geopandas/psycopg2/matplotlib) stays out. Serve versions come from `uv.lock`, never hand-pinned in the `Dockerfile`. A CI `docker-build` job builds + boots the image against a synthetic placeholder snapshot (`scripts/make_placeholder_snapshot.py`) — the drift guard that catches an allowed-but-unpackaged import the denylist import-graph test would miss.

## Public deployment

**Public deployment (E8-S7, #101 / D034).** The container is deployed to **Cloud Run** (scale-to-zero, `--max-instances=1`, request-based CPU) fronted by **Cloudflare (free)** for CDN + rate limiting + bot protection. Runbook: [`docs/deploy-cloud-run.md`](docs/deploy-cloud-run.md); deploy glue: [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) (keyless WIF, `workflow_dispatch`-only). The snapshot is a **data input** built locally from the warehouse → uploaded to a private GCS bucket → pulled into a CI-built, snapshot-hash-tagged image (never built in CI — no warehouse there). **Caching is version-based, not TTL** (D034): the response header stays moderate (`public, max-age=3600, stale-while-revalidate=86400, stale-if-error=86400`), the *long* hold lives in a Cloudflare Edge Cache TTL, and the deploy **purges the edge after cutover** — so between snapshot versions the origin is never woken by reads (true scale-to-zero). **Origin lock-down** (`usvote/api/origin_guard.py`): a stdlib-only middleware rejects direct-to-`run.app` `/v1` hits lacking a Cloudflare-injected secret header — **opt-in + fail-open** (active only when `USVOTE_API_ORIGIN_SECRET` is set; `/health` always exempt; posture surfaced in `/health`), so local dev, the unit suite, and the D033 container smoke test are unaffected. A **budget kill-switch** ([`deploy/killswitch/`](deploy/killswitch/)) pauses the service if spend crosses a threshold (Cloud Run has no native hard cap). The Cloudflare front is a **Worker** (`usvote-api-proxy`), not zone Rules — the free plan paywalls Origin Rules' Host-header override, so the Worker rewrites `Host`→`run.app` (Cloud Run's front end routes by Host — a plain proxied CNAME 404s), injects the secret header, and caches `/v1` via the Cache API ([D035](.claude/specs/decisions.md), revising D034's mechanism; intent unchanged). **Live at `https://api.us-presidential-election-center.org`.**
